## How to Use

### View the Website
1. Navigate to the project folder in VS Code
2. Right-click on `index.html` and select "Open with Live Server"
   - OR - Simply open `index.html` directly in any browser

### Customize Content
1. Edit `index.html` to add church-specific content
2. Update phone, email, address in contact section
3. Replace placeholder titles and descriptions
4. Add church logo and photos in images folder

### Modify Colors
- Edit CSS variables in `styles.css` `:root` section
- Primary color: --primary-color (#e91e63)
- Update dark, light, and accent colors as needed

### Add Features
- Connect social media links in footer
- Add email integration to contact form
- Embed YouTube videos or radio streams
- Connect to prayer request system
- Add event calendar
